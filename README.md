# 🕯️ تداول — محلل الشموع اليابانية بالذكاء الاصطناعي

تطبيق ويب متكامل (يعمل في المتصفح مباشرة بدون سيرفر) لتحليل الأسواق بالشموع اليابانية والمؤشرات الفنية والذكاء الاصطناعي.

## المميزات

| الميزة | التفاصيل |
|---|---|
| 🔑 **4 خانات لمفاتيح API** | Google Gemini أو Anthropic Claude — يتعرف على نوع المفتاح تلقائياً (`AIza...` / `sk-ant-...`)، مع اختيار الموديل وزر اختبار لكل خانة |
| 📷 **تحليل صورة الشارت** | ارفع/اسحب/الصق صورة الشارت ← يحدد **نقطة الدخول، وقف الخسارة، 3 أهداف، نسبة العائد/المخاطرة، هل سيصعد السوق، ونسبة الثقة** |
| 🤝 **تحليل جماعي** | يرسل الصورة لكل المفاتيح معاً ويدمج النتائج (تصويت الأغلبية + الوسيط للأسعار)، أو وضع "تبديل تلقائي" ينتقل للمفتاح التالي عند الفشل |
| 📚 **مكتبة 86 نمط شموع** | كل الأنماط من شمعة واحدة حتى 5 شموع (دوجي، مطرقة، ابتلاعية، نجمة الصباح/المساء، الجنود الثلاثة، الغربان، الهارامي، الطرق الثلاث، الطفل المهجور، تاسوكي، السلم...) مع شرح عربي ورسم توضيحي واكتشاف آلي |
| 📈 **السوق المباشر** | شموع حية: **Binance** للعملات الرقمية (بدون مفتاح) و**Twelve Data** للفوركس والذهب والفضة والأسهم (EUR/USD، XAU/USD، AAPL...) مع شارت ورسم الأنماط وخطوط الدخول/الوقف/الأهداف |
| 📡 **حتى 4 مفاتيح Twelve Data** | منظِّم طلبات ذكي: يوزع الطلبات على المفاتيح، **ينتظر تلقائياً** عند امتلاء رصيد الدقيقة بدل إظهار خطأ، ينتقل للمفتاح التالي عند الرفض، ويحفظ النتائج 55 ثانية. مع عداد استهلاك لكل مفتاح. اكتب الرمز بأي صيغة: `EURUSD` أو `EUR/USD` أو `XAUUSD` |
| 🧭 **قراءة السوق** | تقييم فني شامل بأشهر 26 مؤشراً: 15 متوسطاً متحركاً (EMA/SMA 10–200، Hull، VWMA، إيشيموكو) و11 مذبذباً (RSI، Stochastic، CCI، ADX، AO، Momentum، MACD، Stoch RSI، Williams %R، Bull/Bear Power، Ultimate) ← من "بيع قوي" إلى "شراء قوي"، مع الاتجاه على فريمات 15m و1h و4h و1d |
| ⚡ **تحديث كل 10 ثوانٍ** | يجلب آخر 3 شموع فقط ويعيد التحليل (اختيار 10/30/60 ثانية)، ويتوقف تلقائياً عند إخفاء الصفحة. لرموز Twelve Data يعرض كم يكفي الرصيد اليومي بهذا المعدل |
| 📊 **أفضل المؤشرات** | EMA 9/20/50/200، RSI، MACD، بولينجر، ستوكاستيك، ADX/DMI، إيشيموكو، Supertrend، Parabolic SAR، CCI، Williams %R، MFI، OBV، VWAP، فيبوناتشي، نقاط الارتكاز، دعوم ومقاومات آلية |
| 🌍 **الأسواق العالمية والأخبار** | أسعار وتغير 24 ساعة، العملات العالمية مقابل الدولار (ارتفعت أم انخفضت)، آخر الأخبار، وملخص أخبار بالذكاء الاصطناعي عبر البحث على الويب |

## التشغيل

```bash
npm start          # ثم افتح http://localhost:8080
# أو أي سيرفر ملفات ثابتة:  python3 -m http.server 8080
```

يمكن أيضاً نشره مجاناً على **GitHub Pages** (Settings ← Pages ← اختر الفرع).

> ملاحظة: يجب فتحه عبر `http://` وليس بفتح الملف مباشرة (`file://`) لأن التطبيق يستخدم ES Modules.

## 📱 تطبيق Android (APK)

المشروع مغلّف بـ [Capacitor](https://capacitorjs.com) داخل مجلد `android/`.

**التثبيت على الهاتف:** انقل ملف `Taduol-x.y.apk` للهاتف ← افتحه ← اسمح بـ "التثبيت من مصادر غير معروفة" ← تثبيت.

**بناء APK بنفسك** (يحتاج JDK 21 و Android SDK بمنصة 36):

```bash
npm install
npm run android:sync                 # ينسخ ملفات الويب إلى android/
cd android && ./gradlew assembleRelease
# الناتج: android/app/build/outputs/apk/release/app-release.apk
```

- أيقونة التطبيق وشاشة البداية تُولَّد بـ `python3 scripts/make-icons.py`.
- **التوقيع:** ضع ملف المفتاح و`android/keystore.properties` بهذه الصيغة (الملفان لا يُرفعان للمستودع):
  ```
  storeFile=taduol-release.keystore
  storePassword=...
  keyAlias=taduol
  keyPassword=...
  ```
  استخدم **نفس المفتاح دائماً** حتى تُثبَّت التحديثات فوق النسخة القديمة دون فقدان المفاتيح المحفوظة.
- عند كل تحديث ارفع `versionCode` في `android/app/build.gradle`.

## الخصوصية والأمان

- المفاتيح تُحفظ في `localStorage` على جهازك فقط، وتُرسل مباشرة إلى Google أو Anthropic أو Twelve Data.
- الخطة المجانية لـ Twelve Data: 8 طلبات/دقيقة و800/يوم لكل مفتاح. قائمة المراقبة 6 رموز بمفتاح واحد، و12 رمزاً بمفتاحين أو أكثر.
- استخدم فقط مفاتيح من حسابات يحق لك استخدامها؛ فتح عدة حسابات مجانية لنفس الشخص قد يخالف شروط Twelve Data.
- استخدم مفاتيح بحدود إنفاق منخفضة ولا تستخدم التطبيق على جهاز مشترك.
- Claude يُستدعى عبر مكتبة Anthropic SDK الرسمية من المتصفح؛ الموديل الافتراضي `claude-opus-5-5` مع تفعيل الرجوع التلقائي (fallbacks) على الخادم.
